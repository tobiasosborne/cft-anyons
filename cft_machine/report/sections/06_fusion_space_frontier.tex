\section{The fusion-space locality target and the unfinished machine}

\subsection{Global admissibility is not a locality obstruction}

Tobias's final direction is essential: globally constrained Hilbert spaces
can simply be fusion spaces. A local Hamiltonian on such a space need not
be local on an unconstrained tensor product with independent on-site labels.
The correct question is which fusion labels and vertices a term acts on,
how its matrix elements depend on surrounding admissible data, and how that
action behaves under refinement.

Consequently, the descendant-space construction should neither be dismissed
because it is globally constrained nor declared local because it is finite.
Its missing interface is specific: an identification with categorical fusion
paths and a local operator calculus on those paths. The current project has
fusion-tree conventions and exact Fibonacci local-operator machinery, but
no proved identification between those spaces and the new coset descendant
spaces has been obtained.

\subsection{What a local fusion-space realization would have to establish}

This is a research target, not a claimed theorem. For a chosen input category
and microscopic size, the next construction should specify:
\begin{enumerate}
\item An admissible fusion-path or fusion-tree basis, with unit, bracketing,
charge and inner-product conventions fixed before importing matrices.
\item A map from the constructed microscopic state space into that fusion
space, with a proved inverse or explicitly controlled image.
\item Hamiltonian densities and symmetry ingredients acting on a bounded
neighbourhood of fusion data, including any required F-moves.
\item Refinement maps compatible with those admissibility constraints,
the selected states and the local observable interpretation.
\item The existing OAR and microscopic-symmetry convergence hypotheses in
that realization, plus the sector comparison establishing modular fidelity.
\end{enumerate}

The global constraint should be carried by the space itself. A generic
full-chain penalty projector is not a substitute for the local operator
description. Conversely, the existence of such a projector is not a proof
that a local fusion-space description is impossible.

\subsection{Why the universal algorithm is still open}

The positive constructions do not prove that every unitary modular category
has a conformal realization with computable microscopic data. Existing
source realization theorems for particular families do not automatically
give lattice Hamiltonians or OAR maps. Numerical recognition of a critical
spectrum would not fill that gap.

Nor is a general functor implemented. The Ising code transports declared
presentation labels and factor data. A functor on a broader category of
inputs must specify which tensor morphisms preserve the physical choices,
how states and refinements are transported, and how compositions agree.
The current research notes discuss decorated equivalences as an initial
domain, without claiming arbitrary tensor functors preserve criticality.

The proposed tricritical-Ising modular recognizer was stopped when wind-up
was requested. Its six-sector formula proposal is recorded as unimplemented;
there is no tricritical input compiler or associated acceptance test to claim.
The $c=7/10$ results in this report concern actual coset stress and descendant
constructions, not an already completed new modular-input frontend.

\subsection{What is retained for the next investigation}

The useful output is not merely a list of gaps. The repository now contains
actual microscopic formulas, exact finite vectors and Gram matrices, state
and operator convergence criteria, controlled symmetry limits, positive
finite constrained models, and reproducible regression witnesses. These
can be tested against a candidate local fusion-space model instead of
rebuilding the continuum machinery from scratch.

The work is wound up at the present verified boundary. No general
category-to-CFT result is claimed, and no pending proposal is represented
as implemented. The next scientific step is the local fusion-space
identification specified above.
