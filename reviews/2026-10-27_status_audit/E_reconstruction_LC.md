## 1. The approach in one paragraph

The input is a unitary fusion category C, read as a *chiral sector category*: fusion-only input
"needs a compatible braided completion" (`R/01_cells.md:28-29`). With it comes a module category M.
The unknowns are graded analytic carriers `D_ab = ⊕_i M_ab^i ⊗ V_i`, with V_unit = V the vacuum chiral
algebra to be reconstructed (`R/01_cells.md:19-39`), and cell maps `Z_P: D_in -> D_out ⊗ L_P`
into a Hermitian anomaly line (`:47`). These are constrained by C0–C7 (`:57-162`): categorical typing,
positivity and collars, sewing, decomposition independence, and the coordinate Ward equation.
- **Horizontal equation.** On a coordinate chart the Ward equation is `∂_i Z + B_i^+ Z - Z B_i^- = 0`
  (`R/README.md:47`; C4 at `R/01_cells.md:104`). Collars are positive semigroups (B = E, not skew).
  Genuine moduli instead need a stress-insertion right-hand side, which "remains a schema"
  (`R/01_cells.md:107-116`).
- **Ward sewing identity.** `W_(Z2 Z1) = W2 Z1 + Z2 W1` (LC-W, `R/01_cells.md:173-186`). Composition
  propagates Ward residuals but does not bound them (`:188-195`).
- **Stress is an internal generator.** C6/C7 require that the connection B be generated by the
  stress field ω of the *same* field algebra, with L_-1 = D (`:134-155`). At each cutoff the
  energy/current insertions must equal the *standard* Koo–Saleur (KS) densities built from a local
  Hamiltonian, so the modes are not free fit variables (`:157-162`; `R/04_cutoff_oar.md:61-73`).
- **"Formulating equations vs. finding solutions."** The goal is to write down a countable system
  of coefficient equations and inequalities: Taylor recurrences (`R/01_cells.md:199-214`),
  countability (`:216-220`), and cokernel/cohomology obstructions to formal solvability
  (`R/02`, `R/03`, `R/05`, `R/10`). Existence, convergence and fidelity are deliberately left as
  separate obligations (`R/README.md:4-17`, `:119-125`).
- **Link to Koo–Saleur / OAR (operator-algebraic renormalisation).** LC-4 is the bridge. It fixes a
  periodic nearest-neighbour KS tier (convention (af)), Wilson-state/GNS refinement conditions
  through WT-1, and energy-weighted graph-norm certificates feeding VR-1 (`R/04_cutoff_oar.md:16-138`).
  It explicitly stops short of proving any of these (`:140-160`).

## 3. The obstruction calculations (README table, `R/README.md:72-81`)

1. **Local innerness, HH¹(B,E).** Established: for a declared bimodule E, a Leibniz δ is inner iff
   its class vanishes (`R/02_obstructions.md:38-51`). Boundary: a range-restricted support ansatz is not a
   bimodule, so only a cokernel applies. HH¹ = 0 does not give a continuous selection, bounds or
   self-adjointness (`:58-63`). This is a genuine cohomology statement, but nobody has computed it for
   any cell algebra of the programme. In particular there is no calculation for End_C(A^⊗L), which LC-7
   flags as having nonzero inner derivations (`R/07:189-197`).
2. **Projective lift, CE H².** Established: the defect is central, and once scalar it is a 2-cocycle;
   counterterms shift it by coboundaries (`R/02:67-111`). Boundary: a nonzero class is allowed, and only
   [κ−κ_target] matters. This is genuine but standard Lie theory (Schottenloher `:2236-2264`). P5 adds
   the true finite-dimensional no-go (`:210-224`), which CA-79 reuses (`report/sections/79_ks_shell_and_refinement_defect.tex:202`).
3. **Binary sewing, H³.** Established: the classical Gerstenhaber-type obstruction [O_N] ∈ H³ for a fixed
   associator, fixed unit and frozen geometry (`R/03:94-141`). Boundary stated at `:160-165`.
   *Important:* LC-7 Prop 3 proves HH^{n≥1}=0 for **every** algebra with a separability morphism, at the
   general-C layer (`R/07:137-179`). FRS-type special Frobenius algebras satisfy this, so this
   obstruction group vanishes on exactly the algebras the programme uses. It carries no information there.
4. **Mixed product + action.** Established: D²=0 for the truncated total complex, the coupled
   first-order equations, and gauge (`R/05:74-158`). Boundary: δ is a fixed *external* derivation. There
   is no A(v), no internal stress, no geometry (`:160-167`). Genuine, but for a frozen fragment.
5. **Bounded-support flux.** Established: for a finite patch ansatz the condition is a linear range
   problem coker(D) (`R/04:50-59`). Boundary: δ_n is not a differential, so this is not cohomology (`:57-58`).
6. **Full system.** Only the linearization cokernel coker J (LC-3 §4 `R/03:143-158`; FP-J `R/10:153-180`).
   No identities D_2 J = 0 are derived, so **no complex and no cohomological obstruction theorem exists
   for the full sewing/Ward/stress system** (`R/README.md:81`; `R/10:176-178`).

**Verdict.** Every genuine cohomology theorem here (HH¹, CE H², binary H³, mixed H²) is for a *frozen
fragment*. For the full system there is only the finite-ansatz cokernel criterion, which is linear
algebra. The fragment that is most "obstruction-like" (binary H³) is identically zero for all separable
algebras.

## 7. Honest assessment

LC-1–LC-5 and LC-9/10 are a careful, general-C *formulation*: correct signs, honest boundaries, and
real lemmas (LC-W, FP-D, FP-P, FP-J, the LC-7 contraction). But the unknowns live on the continuum
side: graded carriers V_i, a vertex algebra with conformal vector, and analytic blocks. Solving the
system *is* the open problem of realising a unitary modular category by a chiral CFT. CA-80's review of
Conj. 80.C says this outright (`80_lattice…tex:236-240`). No finite presentation exists, so a general-C
solver has nothing finite to attack. The obstruction calculus is cohomological only on frozen
fragments, and its sharpest piece (binary H³) vanishes for every separable algebra.

The instance phase (06–13) then stalled in exactly the way Rule 16 describes. The only positive
four-port solution uses the semion's degenerate c=1 null and a hand-declared doublet. Fibonacci yields
only necessary conditions. Two lemmas lifted to CA-80 (energy-resolved positivity; the c>1 character
bound) are the generalizable output, and they are worth keeping.

**Single most valuable next step.** Pose LC-1's equations *at finite cutoff on the lattice tower*
instead of on continuum carriers. That is CA-75 Link (a), already written as open questions (a1)–(a3)
(`75_integration_map.tex:115-135`):
- Take CA-86 brick-wall Trotter rectangles Z^lat_P ∈ End_C(O^⊗ℓ) as the cell maps.
- Type the cuts by the CA-80/(al) cut spaces ⊕_a Hom_C(a, W_γ), and sew with the CA-92/CA-98 canonical
  seams.
- Define C4 residuals as anisotropy derivatives compared with KS densities.

Then C2–C4 become finite-dimensional residual equations at each N, for arbitrary C at layer L0/L1.
LC-W supplies their propagation law, and their decay is exactly the A4/W2 estimate targeted by CA-89
and CA-95. The variable-N tower (CA-62–74, with CA-90's local unital lift) supplies the refinement
maps, and CA-81's WT-1/VR-1 contract supplies the OAR acceptance test.

In short: join `reconstruction/` to CA-86 (cells) and CA-89/95 (Ward→KS). Retire further four-port
instance work until the lattice cell equations exist.
