\subsection{Level Data}

An implemented level consists of:
\[
  \mathcal W_{\mathrm{psd}},\qquad
  \mathcal W_{\mathrm{rel}},\qquad
  \mathcal R.
\]
The first set is the row/column basis for the PSD moment matrix.  The second
set supplies \(X,Y\) in \(\omega(X^*RY)=0\).  The third is a list of fixed
residual coefficient terms.

The convenience constructor uses full Pauli-word windows:
\[
  \mathcal W=\{P_s:\operatorname{supp}s\subseteq
  [a,a+L-1]\}.
\]
Optional weight truncation is an implementation diagnostic, not the canonical
hierarchy.

\subsection{Solver Status}

The feasibility problem has no objective.  The status map is:
\[
\begin{array}{c|c}
\text{MOI termination status}&\text{hierarchy verdict}\\ \hline
\texttt{OPTIMAL}&\texttt{:not\_excluded\_at\_level}\\
\texttt{INFEASIBLE},\texttt{INFEASIBLE\_OR\_UNBOUNDED}&\texttt{:excluded}\\
\text{anything else}&\texttt{:solver\_unknown}.
\end{array}
\]
This map is intentionally conservative.

\subsection{Smoke Run}

The run bundle
\[
  \texttt{runs/2026-05-31-qubit-sdp-smoke/}
\]
records three tiny Mosek solves: zero residual, identity-zero relation, and a
forced \(ZZ=0\) relation.  The first is not excluded at the level; the latter
two are excluded.  The \(ZZ\) case is artificial: it forces
\(\omega(ZZ\cdot ZZ)=\omega(I)=0\).
