\subsection{Contract}

Each scan point is a real \(4\times4\) Pauli coefficient matrix
\(h_{\alpha\beta}\).  The gate order is:
\[
  p=i[h_j,h_{j+1}],\qquad A=Du,\qquad
  B-u-\lambda h+\mu I=Dw,
\]
followed, only when requested, by finite moment-SDP checks.

The serialized row records the family, parameters, coefficient matrix, current
norm, witness residual norms, speed data, terminal gate, and scoped verdict.
The scope field records the fixed first-moment route.

\subsection{Verdict Boundary}

\texttt{excluded\_current\_collapsed} and
\texttt{excluded\_no\_conservation\_witness} are early algebraic failures for
the fixed current route.  \texttt{excluded\_no\_boost\_witness} means the exact
local boost-witness equation failed; it does not reject other lattice
stress-tensor constructions such as Koo--Saleur/free-fermion routes.  This
distinction is essential for sourced critical transverse Ising.
